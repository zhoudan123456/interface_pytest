# Excel标注表格填写详细指南

## 📊 表格结构概览

打开Excel模板后，你会看到 **3个工作表**：

```
Sheet 1: 检查点标注      ← 主标注表（主要在这里工作）
Sheet 2: 文件信息        ← 填写文件基本信息
Sheet 3: 类别说明        ← 类别参考表（不用填写）
```

---

## 📝 Sheet 1: 检查点标注表（主表）

### 表格字段说明

| 列号 | 字段名 | 是否必填 | 如何填写 | 示例 |
|------|--------|----------|----------|------|
| A | 序号 | ✅ 必填 | 自动递增数字 | 1, 2, 3... |
| B | 检查点ID | ✅ 必填 | CP-序号 | CP-001, CP-002... |
| C | 检查点文本 | ✅ 必填 | 直接复制原文 | 投标人注册资本不低于1000万元 |
| D | 类别 | ✅ 必填 | 从4个类别中选择 | 资格评审 |
| E | 页码 | ✅ 必填 | 填写数字 | 3 |
| F | 是否必需 | ✅ 必填 | 填写"是"或"否" | 是 |
| G | 备注 | ⭕ 可选 | 简要说明 | 硬性要求、废标项 |

---

## ✍️ 详细填写步骤

### 第1行填写示例

假设你在招标文件第3页找到这个检查点：

```
原文：
3.2 投标人注册资本不低于人民币1000万元。
```

#### 步骤1: 填写"序号"列（A列）
```
填写: 1
```
**说明**: 第1个检查点就填1，第2个填2，依次类推

#### 步骤2: 填写"检查点ID"列（B列）
```
填写: CP-001
```
**说明**: 固定格式 CP-序号（3位数字）
- CP-001, CP-002, CP-003...
- 可以用Excel自动填充：先填CP-001，然后拖动填充柄

#### 步骤3: 填写"检查点文本"列（C列）⭐ 最重要
```
填写: 投标人注册资本不低于人民币1000万元
```

**填写方式**:
1. 在PDF中选择原文
2. Ctrl+C 复制
3. 在Excel该单元格 Ctrl+V 粘贴
4. **重要**: 保持原文完全一致，不要修改任何文字

**注意事项**:
- ✅ 完整复制，不要删减
- ✅ 包括标点符号
- ❌ 不要改写或简化
- ❌ 不要自己总结

#### 步骤4: 填写"类别"列（D列）
```
填写: 资格评审
```

**4个类别选择**（从中选择1个）:

| 类别代码 | 类别名称 | 适用于 |
|----------|----------|--------|
| 1 | 响应性评审 | 符合性检查、报价、文件编制要求 |
| 2 | 形式评审 | 封面、签字盖章、法定代表人 |
| 3 | 综合评审 | 评分项（业绩、人员、方案等） |
| 4 | 资格评审 | 资格要求、资质证书、条件 |

**判断技巧**:
```
看到"注册资本、资质、证书" → 资格评审
看到"报价、限价、预算" → 响应性评审
看到"封面、签字、盖章" → 形式评审
看到"得X分、评分、业绩" → 综合评审
```

#### 步骤5: 填写"页码"列（E列）
```
填写: 3
```

**说明**: 只填数字，不需要"第X页"或"page X"

#### 步骤6: 填写"是否必需"列（F列）
```
填写: 是
```

**判断标准**:
- ✅ 不满足会导致**废标** → 填"是"
- ✅ 不满足会**扣分** → 填"否"（评分项）
- ✅ 资格要求 → 填"是"
- ✅ 评分标准 → 填"否"

**快速判断**:
```
"必须"、"不得"、"应当" → 是
"得X分"、"扣X分" → 否
```

#### 步骤7: 填写"备注"列（G列）（可选）
```
填写: 硬性要求
或
填写: 废标项
或留空
```

**备注填写建议**:
- 硬性要求、废标项、实质性要求
- 特殊说明
- 或留空不填

## 🔍 深入理解：两个字段详细说明

### 字段详解：F列 - "是否必需"

#### 什么是"是否必需"？

**"是否必需"** 判断的是：这个检查点是否为**强制性要求**，不满足会导致什么后果。

---

#### ✅ 填"是"的情况

**不满足会导致废标** 的检查点填"是"：

| 类型 | 示例 | 说明 |
|------|------|------|
| **资格要求** | 注册资本不低于1000万元 | 不满足=无资格 |
| **资质证书** | 须具备一级建造师证书 | 没有证书=无资格 |
| **响应性要求** | 按要求盖章或签字 | 未盖章=废标 |
| **实质性要求** | 报价不超过最高限价 | 超限价=废标 |
| **合规要求** | 不得存在围标串标情形 | 违规=废标 |

**判断标准**：
```
看到这些词 → 填"是"
├── 必须、应当、不得
├── 强制性要求
├── 实质性要求
├── 不符合将废标
├── 资格要求
└── 响应性要求
```

---

#### ❌ 填"否"的情况

**不满足只扣分，不会废标** 的检查点填"否"：

| 类型 | 示例 | 说明 |
|------|------|------|
| **评分项** | 类似业绩：每完成1个得4分 | 没有业绩=扣分 |
| **加分项** | 项目组人员具有高级职称 | 没有高级职称=不得分 |
| **技术方案** | 服务方案：优秀得21分 | 方案差=扣分 |
| **优化建议** | 合理化建议：最高8分 | 没提建议=0分 |

**判断标准**：
```
看到这些词 → 填"否"
├── 得X分、扣X分
├── 最多X分
├── 评分标准
├── 综合评审
└── 评审办法
```

---

#### 🎯 快速判断流程图

**示例1**：
```
检查点: "投标人注册资本不低于1000万元"
    ↓
问题: 不满足会怎样？
    ↓
回答: 没有资格投标 → 废标
    ↓
判断: 填"是" ✅
```

**示例2**：
```
检查点: "供应商近三年以来承接过类似项目的,每完成1个得4分"
    ↓
问题: 不满足会怎样？
    ↓
回答: 扣分，不会废标
    ↓
判断: 填"否" ❌
```

---

#### 📊 按章节判断（快速参考）

| 章节 | 通常"是否必需" |
|------|----------------|
| **第2章 供应商须知** | 大部分填"是" |
| **第3章 评审办法-符合性检查** | 填"是" |
| **第3章 评审办法-评分标准** | 填"否" |
| **第3章 评审办法-综合评分** | 填"否" |
| **第4章 采购需求** | 部分"是"，部分"否" |
| **第6章 响应文件格式** | 填"是" |

---

#### 💡 判断口诀

```
资格要求 → 是
符合性 → 是
实质性 → 是
评分项 → 否
综合评审 → 否
```

**不确定时的处理原则**：
- 宁可填"是"，不要填"否"
- 不确定时在备注中标注"不确定"
- 验证时再确认

---

### 字段详解：G列 - "备注"

#### 什么是"备注"？

**"备注"** 是可选字段，用于添加额外的说明信息，帮助理解或标注。

---

#### 📝 备注的常见用途

##### 1. 标注要求性质

```
填写: "硬性要求"
填写: "实质性要求"
填写: "废标项"
填写: "资格门槛"
填写: "条件式要求"
```

##### 2. 标注特殊说明

```
填写: "表格第1行"
填写: "评分项，20分"
填写: "条件式要求，需根据实际情况判断"
填写: "引用第X章规定"
填写: "需提供证明材料"
```

##### 3. 标注注意事项

```
填写: "需提供证明材料"
填写: "需加盖公章"
填写: "有效期3年"
填写: "副本即可"
```

##### 4. 留空（大多数情况）

```
不填任何内容
```

---

#### 📋 推荐的备注内容速查表

| 情况 | 推荐备注 | 说明 |
|------|----------|------|
| 硬性要求 | "硬性要求" | 不满足=废标 |
| 资格门槛 | "资格门槛" | 必须满足 |
| 实质性要求 | "实质性要求" | 重要条款 |
| 评分项 | "评分项，XX分" | 说明分值 |
| 表格内容 | "表格第X行" | 说明位置 |
| 需要证明 | "需提供证明" | 说明要求 |
| 条件式 | "条件式要求" | 需判断 |
| 特殊情况 | "特殊情况，详见PXX" | 说明位置 |
| 一般情况 | 留空 | 不填 |

---

#### ⚠️ 备注填写建议

**应该填**：
- ✅ 重要说明（硬性要求、实质性要求）
- ✅ 特殊情况（条件式、需判断）
- ✅ 位置信息（表格第X行）
- ✅ 分值信息（评分项，20分）

**不应该填**：
- ❌ 重复的内容（已体现在检查点文本中）
- ❌ 过长的说明（应该简洁）
- ❌ 不确定的信息（容易误导）

#### 示例1: 资格要求（必需）


## ⚡ Excel快捷操作技巧

### 1. 自动填充序列

**序号列（A列）**:
```
1. 在A2单元格填 "1"
2. 在A3单元格填 "2"
3. 选中A2:A3
4. 拖动右下角填充柄向下
```

**检查点ID列（B列）**:
```
1. 在B2单元格填 "CP-001"
2. 在B3单元格填 "CP-002"
3. 选中B2:B3
4. 拖动右下角填充柄向下
```

### 2. 类别下拉选择

**设置数据验证**（一次性设置）:
```
1. 选中D列（类别列）
2. 菜单: 数据 → 数据验证
3. 允许: 序列
4. 来源: 响应性评审,形式评审,综合评审,资格评审
5. 确定
```

### 3. 快速复制粘贴

```
从PDF复制到Excel:
1. PDF中 Ctrl+C 复制文本
2. Excel中 Ctrl+V 粘贴
3. 如果格式有问题，选择性粘贴为"文本"
```

### 4. 冻结首行

```
1. 选中第2行
2. 菜单: 视图 → 冻结窗格 → 冻结首行
3. 这样滚动时表头始终可见
```

填写文件基本信息（只需填写第一行）:

| 字段 | 填写示例 | 说明 |

## 💡 常见问题

### Q1: 检查点文本太长，超出单元格？

**解决方法**:
1. 选中该列
2. 菜单: 开始 → 格式 → 自动换行
3. 或调整列宽
4. 或使用 Alt+Enter 手动换行

### Q2: 不确定选择哪个类别？

**判断方法**:
1. 先看是否为评分项 → 是则选"综合评审"
2. 再看是否为资格要求 → 是则选"资格评审"
3. 再看是否为形式要求 → 是则选"形式评审"
4. 其他情况选"响应性评审"

### Q3: 复制过来的文本有多余空格？

**清理方法**:
```
1. 选中该列
2. Ctrl+H 查找替换
3. 查找内容: 空格
4. 替换为: (留空)
5. 全部替换
```

### Q4: 如何快速统计检查点数量？

**方法1: 使用公式**
```
在任意单元格输入: =COUNTA(C:C)-1
```

**方法2: 查看状态栏**
```
选中检查点文本列，右下角会显示计数
```
