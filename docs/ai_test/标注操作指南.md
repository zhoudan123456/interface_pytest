### 第3步：开始标注（30-45分钟）⚠️ 核心步骤

### 3.1 标注操作流程

```
┌─────────────────────────────────────────────────────┐
│              标注操作四步法                          │
└─────────────────────────────────────────────────────┘

步骤1: 快速浏览 (5分钟)
├── 翻阅招标文件，了解章节结构
├── 重点查看目录，标记重要章节
└── 特别关注：第2、3、4、6章

步骤2: 逐页标注 (20-35分钟)
├── 从第1页开始，逐页查找检查点
├── 找到检查点后，填写Excel表格
└── 继续下一页，直到标注完成

步骤3: 重点复查 (5分钟)
├── 重点章节再次检查
├── 表格、列表特别关注
└── 脚注、附件不要遗漏

步骤4: 保存文件 (1分钟)
├── Ctrl+S 保存Excel文件
└── 另存为：annotations/标注_文件名.xlsx
```

### 3.2 如何识别检查点

#### 🔍 方法1：关键词搜索法

在PDF中搜索以下关键词：

**强制性词汇**:
```
必须、应当、不得、要求
符合...规定、满足...条件
```

**证明材料**:
```
提供...证明、附...证书
提交...材料、需出具...
```

**评分标准**:
```
得X分、扣X分、最多X分
评分标准、评审办法
```

**示例搜索**:
```
搜索 "必须" → 找到15个结果 → 逐一判断是否为检查点
搜索 "不得" → 找到8个结果 → 标注其中的检查点
```

#### 🔍 方法2：章节定位法

**重点关注章节**:

| 章节 | 名称 | 检查点密度 | 标注优先级 |
|------|------|------------|------------|
| 第2章 | 供应商须知 | ⭐⭐⭐⭐⭐ | 最高 |
| 第3章 | 评审办法 | ⭐⭐⭐⭐⭐ | 最高 |
| 第4章 | 采购需求 | ⭐⭐⭐⭐ | 高 |
| 第6章 | 响应文件格式 | ⭐⭐⭐⭐ | 高 |

**标注技巧**:
- 先标注第3章（评审办法），通常检查点最多
- 再标注第2章（供应商须知），资格要求集中
- 最后标注第4、6章

### 3.3 Excel表格填写说明

#### 表格结构

打开Excel后，你会看到3个工作表：

**工作表1: 检查点标注**（主标注表）
**工作表2: 文件信息**
**工作表3: 类别说明**

#### 填写"检查点标注"表

| 字段 | 如何填写 | 示例 |
|------|----------|------|
| **序号** | 自动递增 | 1, 2, 3... |
| **检查点ID** | CP-序号（自动填充） | CP-001, CP-002... |
| **检查点文本** | ⭐ 直接复制原文 | 投标人注册资本不低于1000万元 |
| **类别** | 从下拉框选择 | 资格评审 |
| **页码** | 填写所在页码 | 3 |
| **是否必需** | 填写"是"或"否" | 是 |
| **备注** | 可选 | 硬性要求、废标项 |

#### 类别选择说明

**4个一级类别**:

1. **响应性评审** - 响应性要求
   - 符合性检查
   - 报价要求
   - 文件编制要求
   - 围标串标检查

2. **形式评审** - 形式要求
   - 封面检查
   - 签字盖章
   - 法定代表人

3. **综合评审** - 评分项
   - 类似业绩
   - 项目组人员
   - 服务方案
   - 其他评分项

4. **资格评审** - 资格要求
   - 资格条件
   - 资格审查
   - 证书要求

```

检查点文本: 响应文件编制：未按磋商文件要求盖章或签字(签章)
```

### 3.5 边界情况处理

#### 情况1：表格中的检查点

**处理方式**: 每行独立标注

**原文**:
```
| 检查项 | 说明 |
|--------|------|
| 报价完整 | 报价不存在缺项、漏项 |
| 报价合理 | 总报价不超过最高限价 |
```

**标注为2个检查点**:
```
CP-004: 磋商报价：报价不存在缺项、漏项
CP-005: 磋商报价：总报价不超过项目(分包)预算金额或最高限价
```

#### 情况2：复合要求（一个句子多个要求）

**处理方式**: 拆分为多个检查点

**原文**:
```
项目经理须具有一级建造师资格证书，且具有5年以上相关项目管理经验。
```

**标注为2个检查点**:
```
CP-006: 项目经理须具有一级建造师资格证书
CP-007: 项目经理具有5年以上相关项目管理经验
```

#### 情况3：列表项

**处理方式**: 每条独立标注

**原文**:
```
投标人须提供：
(1)营业执照副本
(2)资质证书副本
(3)安全生产许可证
```

**标注为3个检查点**:
```
CP-008: 投标人须提供营业执照副本
CP-009: 投标人须提供资质证书副本
CP-010: 投标人须提供安全生产许可证
```

## 💡 标注技巧

### 提高效率的技巧

1. **使用快捷键**
   - PDF阅读器：Ctrl+F 搜索关键词
   - Excel：Ctrl+C/V 复制粘贴
   - Alt+Tab 切换窗口

2. **批量处理**
   - 先标注同一类别的检查点
   - 先标注表格中的所有项
   - 先标注评分项

3. **保持节奏**
   - 每15分钟休息一次
   - 一次标注一份文件
   - 不要追求100%完美

### 常见错误避免

❌ **错误做法**:
- 标注了所有内容（包括说明文字）
- 漏掉了表格中的检查点
- 复制文本时错字漏字
- 忘记填写页码

✅ **正确做法**:
- 只标注实质性要求
- 仔细检查表格和列表
- 复制后检查文本完整性
- 填写完整信息

## 🆘 遇到问题？

### Q1: 不确定是否为检查点？

**判断标准**:
- ✅ 不满足会导致废标 → 是检查点
- ✅ 不满足会扣分 → 是检查点
- ✅ 需要提供证明材料 → 是检查点
- ❌ 一般性说明 → 不是检查点
- ❌ 流程描述 → 不是检查点

**当不确定时**:
- 先标注（宁可多标）
- 在备注中标注"不确定"
- 验证时再确认

### Q2: 文本太长怎么办？

**处理方法**:
- 保留完整文本（复制整句）
- 不要删减或改写
- 如果文本超长，在备注中说明

### Q3: 同一要求出现多次？

**处理方法**:
- 只标注一次（在首次出现的位置）
- 在备注中注明"适用全文"
- 选择页码较小的位置
