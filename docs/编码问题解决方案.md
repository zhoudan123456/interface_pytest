# Windows终端中文乱码问题解决方案

## 问题描述
在Windows终端运行Python脚本时，中文输出显示为乱码。

## 解决方案

### 方案1：使用UTF-8批处理脚本（推荐）✅

**使用方法：**
```bash
run_llm_matcher_utf8.bat excel_file.json result.json
```

这个批处理脚本会自动设置UTF-8编码，无需额外配置。

---

### 方案2：手动设置环境变量

**在命令提示符中：**
```cmd
chcp 65001
set PYTHONIOENCODING=utf-8
python run_llm_matcher.py excel_file.json result.json
```

**在PowerShell中：**
```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$env:PYTHONIOENCODING = "utf-8"
python run_llm_matcher.py excel_file.json result.json
```

---

### 方案3：使用Python模块（高级）

在Python脚本开头添加：
```python
from utils.encoding_helper import safe_print

# 使用 safe_print 替代 print
safe_print("这是中文内容")
```

---

### 方案4：使用GUI界面（最简单）

直接运行GUI程序，不会有编码问题：
```bash
python bid_check_gui.py
```

GUI界面使用文本控件显示，不会出现乱码。

---

## 临时解决方案（推荐给快速测试）

如果你想快速测试而不想配置编码，可以：
1. 将输出重定向到文件：`python script.py > output.txt 2>&1`
2. 使用IDE（如VSCode、PyCharm）运行脚本
3. 使用GUI界面

---

## 推荐工作流程

**日常使用：**
- 使用 `run_llm_matcher_utf8.bat` 运行命令行工具
